3 · Damage comparison

Chart assumes each character performs the chosen ATK-scaling action once per cycle. In cycle 1, the Opening multiplier is used; afterward the Sustained multiplier is used. No effects are carried between cycles beyond this explicit change.

Formula used for ordinary hits

Base = displayed ATK × user-entered action multiplier
DEF = (attacker level + 20) / ((attacker level + 20) + (enemy level + 20) × (1 − DEF reduction))
RES = clamp(1 − enemy RES, 0.1, 2.0)
CRIT = 1 + clamp(CRIT Rate, 0, 1) × CRIT DMG [expected view]
Damage = Base × (1 + DMG bonus) × CRIT × DEF × RES × (1 + vulnerability) × toughness

This controlled normal-hit model deliberately excludes variable kit multipliers, additional damage instances, per-member elemental bonuses, Light Cone conditional passives, support mechanics, enhanced attacks, DoT and Break formulas, Elation, True DMG, weakness break damage, target count and real action order. Values are decimal formula results rounded only for display; the game may use hidden decimals and per-hit rounding.

5 · Production simulator milestone list

  1. Versioned 4.7+ character kit definitions, including every upgrade, buff, Light Cone, set and specific damage type.
  2. Accurate event timeline: Speed, action value, ultimates, energy, SP, summons, enemies, wave transitions and cooldowns.
  3. Separate kernels for direct hits, Break, Super Break, DoT, FUA, Elation, True DMG, fixed damage and HP-based effects.
  4. Encounter configurations: Memory of Chaos, Pure Fiction, Apocalyptic Shadow and a neutral benchmark, with the same enemy details for every team.
  5. Monte Carlo trials for variable targeting, CRIT and enemies; plot mean, best/worst, distribution, per-cycle damage, contribution and confidence intervals.
  6. Regression tests against in-game examples; never label an unsupported kit's result exact.

For this proof of concept, values for each character come solely from your supplied HoYoLAB JSON. No external sites or your account credentials are contacted by the page.

8 · Team Finder & Combat Math v0.5 foundation

Automatically find roster-compatible four-character team templates, then compare their direct-hit reference damage over HSR action-value cycle windows. Select any character composition and inspect a full numerical breakdown of each modeled hit.

Important: these are NOT the strongest-team rankings yet. The team templates are curated candidate compositions, not mathematically optimized or ordered by actual DPS. The new calculations evaluate explicit Basic ATK direct-hit components with a turn clock and optionally assumed active buffs. They do not simulate full Skills, Ultimates, Energy, Skill Points, Relic and Light Cone conditional passives, counters, DoTs, Break, Memosprites, Elation, or complete rotations. They cannot determine the strongest team until those mechanics are implemented and validated. Imported stats include equipped gear's displayed contributions; additional passives are not re-applied.
